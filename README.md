# IT380 – Systems Engineering and Integration Project

**Business Process Automation: Assignment Submission Automation Case Study**

Analysis and automation of the assignment submission process using BPMN modeling and MuleSoft Anypoint Studio. The solution integrates Google Drive, Gmail, and a JSON-based assistant database to automatically zip, upload, and email student assignments.
